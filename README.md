# Планировщик задач

Проект представляет собой веб-приложение для управления задачами с поддержкой повторяющихся событий. Основной функционал:
- Создание, редактирование, удаление задач;
- Отметка выполнения задач с автоматическим обновлением даты для повторяющихся событий;
- Поиск задач по дате, заголовку или комментарию;
- Расчёт следующей даты для задач с правилами повтора (ежедневно, еженедельно, ежемесячно, ежегодно).

## Выполненные задания со звёздочкой
Выполнены все задания повышенной сложности, кроме механизма аутентификации (возможно будет выполнено позднее, но это не точно).

## Инструкция по запуску локально

Для запуска необходим установленный Go.
### Шаги:
1. Клонируйте репозиторий:
   git clone https://github.com/DDmitrievskiy/go_final_project
   cd go_final_project
2. Установите зависимости:
   go mod download   
3. Настройте окружение:
   cp .env.example .env
4. Запустите приложение:
   go run main.go
   Или соберите бинарник:
   go build -o app ./ && ./app
5. Открыть в браузере:
   http://localhost:7540


### Запуск тестов

В файле tests/settings.go можно настроить параметры базы данных для тестов. 
Для запуска тестов выполните команду go test ./tests

### Сборка и запуск через Docker

Соберите образ с помощью docker build -t scheduler-app .
Команда для запуска контейнера docker run -d -p 7540:7540 -v /путь/к/вашей/папке/data:/db -e TODO_DBFILE=/db/scheduler.db scheduler-app     

-v /путь/к/вашей/папке/data:/db      # монтирует директорию хоста в контейнер для хранения SQLite-базы.
-e TODO_DBFILE=/db/scheduler.db      # Путь к базе внутри контейнера
